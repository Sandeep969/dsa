# dsa

Doing one DSA problem a day to stay sharp. Solutions are in Python.

I'm going topic by topic: arrays/hashing, two pointers, sliding window, stack, binary search,
linked lists, trees, tries, heaps, backtracking, graphs, DP, greedy, intervals, math, bits.
The full list I'm working through is in `roadmap.json` (144 problems).

Each folder has `solution.py` (with a few test cases at the bottom) and `notes.md` with what I
want to remember when revising.

```
python3 scripts/dsa.py next      # next problem on the list
python3 scripts/dsa.py test      # run all solutions
python3 scripts/dsa.py progress  # update the table below
```
